The brand's call to action — letterspaced serif capitals in a 3px-radius rectangle. Use for Add to basket, Shop the range, Read the ritual.

```jsx
<Button variant="accent" size="lg">Add to basket</Button>
<Button variant="secondary">Read the ritual</Button>
```

The accent variant reads --accent from the nearest [data-accent] scope, so the same button turns wine on an Egyptian Sunset page and moss on a Wildwood page. Ghost is an underlined text link in disguise — use it for tertiary actions only. Never stack more than two buttons side by side.
