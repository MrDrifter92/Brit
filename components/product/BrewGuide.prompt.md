Right column of the blend panel. All three blends currently share the same guide, so the default needs no props.

```jsx
<BrewGuide />
```

The page must load the Tabler Icons webfont for the glyphs to render:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@tabler/icons-webfont@3.31.0/dist/tabler-icons.min.css">
```

Use the en dash in 7–10, and a degree symbol on 100°C.
